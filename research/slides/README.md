# Presentation slides

15 slides, about 13 minutes. The same deck is published privately as an Artifact.

- `slides.pdf` — all 15 slides as one PDF, for presenting or handing in.
- `png/` — one 1920×1080 image per slide, numbered in presentation order.
- `source/` — the deck source: `deck.json` (slide order and sections), `deck.css` (shared styles) and one HTML file per slide.

The PDF and PNGs were rendered offline with headless Chrome, so they use a system fallback font instead of Space Grotesk / Inter. The layout and numbers are the same as in the published deck.

Every number on the slides comes from the test period and matches `final_report.pdf`.
