# Notebooks

Jupyter notebooks (`.ipynb`) live here: exploration, experiments and analysis.

- Read datasets from the top-level [`data/`](../../data/) directory, do not
  copy data files next to the notebooks.
- Clear large outputs before committing, since embedded outputs can contain
  data and bloat the history.
- Move code that is reused across notebooks into
  [`src/scripts/`](../scripts/).
